A horizon-averaged rank-occupancy forecaster for Roblox's Up-and-Coming top 10: it models each game's rank trajectory from its velocity and playing-growth momentum, spreads honest calibrated probabilities over the 72-hour window, and blends in a persistence baseline for the chart's most stable places.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
